# Math and Computing Foundations

A collection of computational experiments and implementations for strengthening
my mathematical and programming foundations using Python.

The repository focuses on connecting mathematical concepts with practical
implementation, experimentation, testing, and numerical analysis.

## Areas

- Calculus and numerical methods
- Linear algebra
- Probability and statistics
- Discrete mathematics
- Data structures and algorithms

## Approach

For each topic, I implement selected concepts from first principles where
practical, test the implementations, and compare numerical results with
expected or reference values.

The goal is not to reproduce textbook material, but to understand how
mathematical ideas behave when translated into computational procedures.
